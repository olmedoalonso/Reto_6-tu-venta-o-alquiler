# Guía para contribuir

¡Gracias por colaborar con **Te colaboro en tu venta o alquiler...**! Este proyecto busca mejorar el acceso a información sobre propiedades en venta y alquiler en Chitré inicialmente.

## 1. Proponer ideas o mejoras

Abre un **Issue** en GitHub con un título descriptivo. Explica qué problema observaste, a quién afecta, qué solución propones y cómo comprobarías que funciona. Ejemplos: filtros de precio, fichas de inmuebles, accesibilidad móvil, diseño de marca y estrategias de difusión.

## 2. Reportar errores

Indica los pasos para reproducir el error, el resultado esperado, lo que ocurrió, el dispositivo/navegador (si aplica) y capturas **sin datos personales**. No publiques contraseñas, tokens de ArcGIS, teléfonos privados ni ubicaciones sensibles.

## 3. Aportar documentación o recursos

Puedes mejorar instrucciones, corregir textos, crear diagramas, proponer prototipos de interfaz o preparar materiales de difusión. Usa materiales propios, libres o autorizados e indica su procedencia y licencia cuando corresponda.

## 4. Solicitar cambios mediante Pull Request

1. Abre un Issue o selecciona uno existente.
2. Crea una rama desde `main`, por ejemplo `mejora/diseno-filtros`.
3. Modifica los archivos pertinentes y comprueba enlaces, ortografía y consistencia.
4. Realiza un commit con un mensaje claro, por ejemplo `docs: agregar criterios de filtros`.
5. Abre un Pull Request hacia `main` e indica el Issue relacionado, los cambios realizados, por qué son útiles y cómo fueron revisados.
6. Atiende comentarios y, tras la revisión, integra el Pull Request mediante **Merge**.

## 5. Criterios de aceptación

- La contribución responde a una necesidad concreta.
- El texto distingue entre funcionalidades existentes y propuestas.
- No expone datos personales, credenciales ni información confidencial.
- Puede comprenderse por personas no técnicas.
- Si cambia un flujo ArcGIS, explica los permisos y las pruebas necesarias.

## 6. Convivencia

Mantengamos un trato respetuoso y constructivo. Las sugerencias deben centrarse en mejorar el proyecto y su utilidad comunitaria.
